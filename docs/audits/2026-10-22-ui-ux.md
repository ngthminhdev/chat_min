## Kiểm chứng

- `npm test`: 3/3 unit tests hiện có đạt. Các test này chỉ bao phủ formatting, không thay thế kiểm tra UI.
- `npm run build`: TypeScript + Vite build đạt. Còn cảnh báo chia chunk của `bridge.ts` vì cùng được static/dynamic import; không gây build failure.
- Kiểm tra whitespace bằng `git diff --no-index --check` giữa bản sao trước audit và 8 file nguồn đã sửa: không có lỗi.
- Browser demo: xem chat ở 1280×800, 900×650, 390×844; nút gửi và toolbar nằm trong cửa sổ.
- 900px: workspace rộng 578px; mở inspector rộng 360px phủ lên workspace, không chiếm thêm cột.
- 390px: mở sidebar, chọn chat và quay lại; sidebar tự đóng; draft của chat A không lọt sang chat B và được khôi phục khi quay lại A.
- Inbox: nhập từ không có kết quả, xoá bộ lọc và khôi phục danh sách. Settings và bước chọn nền tảng của wizard hiển thị được ở 390px.
- Palette: Tab/Shift+Tab được giữ trong hộp; Escape đóng và trả focus về nút mở sau animation.
- Dialog đổi tên: tên toàn khoảng trắng bị chặn; Shift+Tab vẫn ở trong dialog; huỷ không thay đổi account.
- Fault injection tạm thời qua CDP trên bridge demo: search reject hiện lỗi, khôi phục API rồi thử lại có kết quả; query `budget` chậm 600ms không ghi đè query mới không có kết quả.
- Fault injection edit reject: draft và edit context còn nguyên; khôi phục API và lưu lại thành công. Input/attachment/save được khoá trong lúc chờ.
- Gửi một tin demo thành công và một tin chứa `fail`: có message tương ứng và lỗi gửi kèm nút thử lại. Reload cuối phiên loại bỏ message demo và các API override; draft kiểm thử đã xoá.
- Console sau reload cuối: không có warn/error được ghi nhận.

## Giới hạn kiểm thử

Chưa kiểm tra native Tauri với account thật: OAuth/OTP, gửi/nhận thực tế, file picker, notification OS và reconnect. Boot-error/retry mới được kiểm tra bằng build và đọc mã; chưa giả lập lỗi boot end-to-end. Nút xem thêm >300 hội thoại chưa được thử bằng bộ dữ liệu lớn. Chưa chạy screen reader hoặc đo WCAG contrast trên toàn bộ theme.
